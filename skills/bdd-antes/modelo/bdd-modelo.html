Como ler este BDDHow to read this BDD

BDD (Behaviour-Driven Development, "desenvolvimento guiado por comportamento") é uma forma de descrever o que um sistema faz em frases de gente, antes de olhar o código. Cada frase é um cenário, com três partes:BDD (Behaviour-Driven Development) describes what a system does in plain sentences, before looking at the code. Each sentence is a scenario, in three parts:

PartePartQuer dizerMeans
DadoGivena situação em que você está antes de agirwhere you are before acting
QuandoWhena ação: um comando que você digita ou um botão que você clicathe action: a command you type or a button you click
EntãoTheno que deve acontecer, e que dá para conferir com os olhoswhat must happen, which you can check with your own eyes
Como as abas funcionam. Cada tela, ou lugar para onde uma ação te leva, tem a sua aba. Um botão azul aqui é um botão que existe de verdade no produto; clicar nele leva à aba onde você vai parar. Um link com seta faz o mesmo. Para pular direto, use o menu Ir para a aba. O botão Voltar do navegador também funciona.How the tabs work. Every screen, or place an action takes you, has its own tab. A blue button here is a real button in the product; clicking it takes you to the tab where you would land. An arrow link does the same. To jump directly, use the Go to tab menu. The browser's Back button works too.
Os links se conferem sozinhos. Ao abrir esta página, um verificador passa por todos os links. Se algum apontar para uma aba que não existe, ele fica vermelho e o aviso abaixo muda.Links check themselves. When this page opens, a checker walks every link. If one points to a tab that does not exist, it turns red and the notice below changes.
